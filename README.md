# Milana Gift

Откройте `index.html` для основной версии. Подарок откроется 18 декабря 2026 года в 00:00 по Москве.

Откройте `test.html` для репетиции. При каждой загрузке тестовой страницы отсчёт начинается с 10 секунд. После отсчёта доступны те же коробочка, подвеска и письмо.

Для локального сервера запустите `node server.cjs` и откройте адрес из терминала. Для репетиции добавьте к адресу `/test.html`.

Команды `npm test` и `npm run build` используют зависимости из `package-lock.json`. Готовый 3D-бандл уже включён.

При обновлении CSS или JavaScript обновите параметр `v` у изменённого файла в `index.html`, чтобы браузер загрузил свежую версию.
