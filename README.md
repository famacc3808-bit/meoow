# Милане — в восемнадцать

Откройте `index.html` двойным щелчком. Все материалы, шрифты Literata и Manrope и Three.js хранятся локально: интернет не нужен. Или запустите `npm start` из этой папки и откройте напечатанный адрес.

Новый футляр — настоящая WebGL-сцена: скруглённые стенки, утопленная подложка, шарнирная крышка, освещение и тени. Ожерелье — плоское фотографическое изображение с прозрачным фоном на подложке, не 3D-модель. Его силуэт и цепочка взяты из исходного фото, оригиналы не изменены. При отсутствии WebGL показывается упрощённый футляр без объёмной анимации; письмо остаётся доступным.

Нажмите «Открыть коробочку», затем «Прочитать письмо». Возврат сохраняет открытый подарок; «Открыть ещё раз» закрывает его. Кнопки работают с Tab и Enter. При уменьшении движения крышка переключается без анимации. Звука нет.

## Изменить текст
Согласованные пять абзацев сохранены без изменений в `letter.js`. Короткие обращения — в `index.html`.

## Разработка
`npm ci` устанавливает зафиксированные зависимости. `npm run build` собирает `scene.js` в локальный `assets/scene.bundle.js`. `node prepare-scene.cjs` повторяет подготовку фотографии и копирует шрифты из зависимостей. Старый `prepare-assets.py` относится только к прежним копиям фото и новым сайтом не используется.
`npm test` — структурные проверки. Они не заменяют проверку браузером и визуальную оценку.

Сайт не опубликован. Локальная ссылка доступна только на этом компьютере. После публикации письмо сможет прочитать любой обладатель ссылки; noindex не является защитой доступа.
